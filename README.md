# Hollows: engine work case study

A one-page case study of the engine systems I built for **Hollows**, a 2D stealth horror game on a custom C++20 engine (DigiPen Institute of Technology Singapore, Sep 2025 – Apr 2026).

**Live page:** https://qayzan.github.io/hollows-case-study/

What I built: the FMOD audio engine and mixer, physics and collision with a uniform-grid broad phase, local and cloud saves (Supabase REST over WinHTTP), gamepad support with unit tests, and ImGui editor tools.

The game's source code is a school project and is not public. This repository only holds the case study page, the trailer and screenshots.
